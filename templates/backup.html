A backup group is a fixed list of ZFS datasets. It is written to sets — a ring of backup disks that are used in turn, so each disk in a set is a spare for the others. The first run on a set captures a full snapshot of every dataset plus the current configuration; later runs send only what changed. Full and incremental runs are gzip snapshot-streams.
